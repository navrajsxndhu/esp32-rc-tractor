\# ESP32 RC Tractor Project



An advanced RC tractor project built using ESP32 and PS4 Controller.



\## Features



\- Wireless PS4 Bluetooth control

\- Multi-servo control system

\- Steering servo

\- Rear hydraulic lift simulation

\- Smart headlight system

\- Rear reverse lights

\- Battery voltage monitoring

\- PS4 battery LED indication

\- Embedded robotics control



\## Hardware Used



\- ESP32 DevKit V1

\- PS4 Controller

\- Servo Motors

\- LEDs

\- 3S Li-ion Battery

\- Buck Converter



\## GPIO Pin Mapping



| Function | GPIO |

|---|---|

| Movement Servo | 23 |

| Steering Servo | 14 |

| Lift Servo 1 | 2 |

| Lift Servo 2 | 32 |

| Headlight 1 | 26 |

| Headlight 2 | 27 |

| Rear Light 1 | 33 |

| Rear Light 2 | 25 |

| Battery Monitor | 34 |
